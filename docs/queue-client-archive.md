# QueueClient 归档说明

`experimental/Client/` 目录下的 `QueueClient`、`QueueClient.Desktop`、`QueueClient.Browser`、`QueueClient.Android` 是一组历史实验项目，用于验证“通过手机或其他终端查看渲染进度”的想法。

当前这些项目已从 solution 主线中移除，但源码仍保留在仓库里，原因如下：

- 需求方向是合理的，但现有实现更像原型，不适合作为长期维护的正式产品线
- 当前远程查看架构与主程序耦合方式较弱，没有形成稳定的共享契约与部署方案
- 多端 Avalonia 客户端会显著增加维护面，而未来官网、购买、授权、监控更适合统一收敛到 Web 端

后续推荐演进方向：

- 使用统一的 Web Dashboard 替代独立 Android/Browser/Desktop 远程监控客户端
- 将远程状态查询、日志查看、许可证管理、下载入口整合到同一套 Web 系统
- 在服务端收敛 API 契约、认证方式与部署模型后，再决定是否需要重新引入专用客户端

如果未来确认不再需要这些实验项目，可以再做一次物理迁移或彻底删除；当前阶段优先保留历史实现，避免丢失可复用的界面和交互思路。

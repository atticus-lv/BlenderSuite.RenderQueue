Thank you for helping improve Blender Render Queue.

By submitting a contribution, you agree to the
[Contributor License Agreement](CONTRIBUTOR_LICENSE_AGREEMENT.md). This is
needed because the project is dual-licensed under AGPLv3 and separate
commercial licenses.

## License Expectations

- Project code is licensed under `AGPL-3.0-only` unless a file says otherwise.
- Contributions must be compatible with `AGPL-3.0-only`.

- Do not submit private, proprietary, or confidential code.
